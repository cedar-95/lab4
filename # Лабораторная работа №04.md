## Среда выполнения

- Оболочка: Bash

---

## Создание локального репозитория

- Создание каталога: `mkdir git-extended`
- Переход в каталог: `cd git-extended`
- Инициализация репозитория: `git init`

---

## Первый коммит

- Создание файла: `echo "# git-extended" > README.md`
- Добавление файла: `git add .`
- Фиксация изменений: `git commit -m "first commit"`

---

## Создание удалённого репозитория на GitHub

- Создание нового репозитория на GitHub
- Подключение удалённого репозитория: `git remote add origin <URL>`
- Отправка файлов: `git push -u origin master`

---

## Добавление нового файла и коммит

- Создание нового файла
- Добавление: `git add .`
- Коммит: `git commit -m "new file"`
- Отправка: `git push`
